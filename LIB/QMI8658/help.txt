＜クラス名およびバージョン＞
QMI8658
ver 0.9

＜ファイル名＞
QMI8658.BAS

＜ライセンス＞
BASファイルは、パブリックドメイン

＜概要＞
I2C接続された6軸加速度センサQMI8658シリーズで現在の加速度、角速度を得る
タップ、ダブルタップを検出する（QMI8658A）

＜コンストラクター＞
NEW(QMI8658,a,b,add)
　I2Cを400KHzに設定し、QMI8658シリーズをリセットし初期設定を行う
　加速度、角速度検出を有効にし、6つのパブリックフィールド変数に検出値を書き込む
　ODR（Output Data Rate）は加速度、角速度とも896.8Hzに設定

　a:加速度の検出範囲
　　0:±2g、1:±4g、2:±8g、3:±16g、省略時は1　※gは重力加速度
　b:角速度の検出範囲
　　0:±16deg/s、1:±32deg/s、2:±64deg/s、3:±128deg/s、4:±256deg/s、5:±512deg/s、6:±1024deg/s、7:±2048deg/s
　　省略時は5
　add:I2Cのアドレス、省略時は0x6B

＜パブリックフィールド＞
AX#,AY#,AZ#
　それぞれX軸、Y軸、Z軸の検出された加速度。単位は重力加速度g

GX#,GY#,GZ#
　それぞれX軸、Y軸、Z軸の検出された角速度。単位はrad/s

＜パブリックメソッド＞
CALIB(ax#,ay#,az#)
　静止状態で加速度センサーの較正を行う
　ax#,ay#,az#は各軸の静止状態での加速度の理論値
　例　CALIB(0,0,-1.0)　センサーが基板裏面に水平に設置された場合

GETACC()
　現在の各軸の加速度、角速度を検出し、6つのパブリックフィールド変数を更新する

GETTAP()
　前回呼び出し以降に検出されたタップ情報を8ビットの値で返す
　タップが検出されなかった場合0を返す
　初めて呼び出した時はタップ検出機能の有効化を行う
　定期的に呼び出すことで検出漏れを防ぐ

　bit7  :検出したタップの軸の向き　0:正、1:負
　bit6  :不使用
　bit5-4:検出したタップの軸 0:検出なし、1:X軸、2:Y軸、3:Z軸
　bit3-2:不使用
　bit1-0:検出したタップの種類 0:検出なし、1:シングルタップ、2:ダブルタップ

RESET()
　QMI8658をリセット

＜使用例＞
加速度、角速度検出
USECLASS QMI8658
Q=NEW(QMI8658)
Q.CALIB(0,0,-1.0)
CLS
DO
 CURSOR 0,0
 PRINT SPRINTF$("AX:%+.2f",Q.AX#)
 PRINT SPRINTF$("AY:%+.2f",Q.AY#)
 PRINT SPRINTF$("AZ:%+.2f",Q.AZ#)
 PRINT SPRINTF$("GX:%+.2f",Q.GX#)
 PRINT SPRINTF$("GY:%+.2f",Q.GY#)
 PRINT SPRINTF$("GZ:%+.2f",Q.GZ#)
 WAIT 1
LOOP

タップ検出
USECLASS QMI8658
Q=NEW(QMI8658)
DO
 T=Q.GETTAP()
 IF T THEN PRINT HEX$(T)
 WAIT 1
LOOP
